Fardin Demo Portfolio (React + TypeScript + Vite)

This folder contains a self-contained Vite React + TypeScript demo of the Fardin portfolio.

Quick start:

```bash
cd /Users/alif/Downloads/Fardin/fardin
npm install
npm run dev
# open http://localhost:5173
```

Important: place the real profile photo at `public/fardin-photo.jpg` before running so the avatar and favicon display.
